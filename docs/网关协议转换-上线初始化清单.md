# 网关协议转换（HTTP → Thrift）— 上线初始化清单

> 用途：这份文件专门记「上线时要一并执行的 DDL + 菜单初始化语句」。
> 用户口径：**这些语句不要丢，项目上线时一起初始化**，与 gw_* 既有表、既有网关菜单的初始化方式保持一致。
>
> 关联代码：
> - 网关侧 starter：`autumn-gateway-starters/thrift-autumn-gateway-starter`
> - dashboard 实体/接口：`GwThriftService`、`GwThriftConversion`、`GwThriftController`、`GwThriftConfigService`
> - dashboard-ui 页面：`src/views/gateway/thrift/index.vue`（菜单：网关配置 → 协议转换）
> - 三份 DDL 已同时落进 `autumn-gateway-dashboard/src/main/resources/db/gateway/gw_schema_{mysql,postgresql,h2}.sql`

## 1. 与 Apache ShenYu（HTTP → Dubbo）的对应关系

| ShenYu | 我们（HTTP → Thrift） | 落点 |
|---|---|---|
| Plugin（dubbo）+ selector/rule（URI/Header/Query/Cookie 匹配） | SCG 路由 + `Path/Header/Query` Predicate | `gw_route` 既有能力，不新增 |
| Metadata（serviceName / methodName / parameterTypes） | `gw_thrift_service`：服务地址 + IDL（免接口 jar） | 新表 |
| RpcParamTransformPlugin + param-mapping | `gw_thrift_conversion`：`arguments_json`（BODY/QUERY/HEADER/PATH/FIXED）+ `response_mode` | 新表 |
| GenericService 泛化调用 | `GenericThriftInvoker`（IDL 驱动，`autumn-protocol-extension`） | 已实现，P0 已验通 |
| admin 落库 → 数据同步 → 网关内存 | dashboard 落库 → `GwConfigSyncService` 导出 `autumn.thrift.*` → Consul/Nacos → 网关启动加载 | 已接上（P0 首版） |

差异：ShenYu 靠注册中心 + 注解自动注册 metadata；我们 P0 先用"页面手填服务 + IDL"，P2 再做注册中心/热注册。

## 2. DDL（上线执行，三个方言按现网库选一份）

> 幂等：全部 `CREATE TABLE IF NOT EXISTS`。已写入三份 gw_schema 文件，随 `spring.sql.init` 一起生效；
> 现网若是手工初始化，直接执行下面 SQL 即可。

### 2.1 MySQL 8.0+

```sql
CREATE TABLE IF NOT EXISTS `gw_thrift_service` (
    `id`               BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键',
    `service_code`     VARCHAR(64)  NOT NULL COMMENT '服务编码：必须等于 IDL 里的 service 名，导出为 autumn.thrift.services[].name',
    `service_name`     VARCHAR(128) NOT NULL DEFAULT '' COMMENT '展示名（中文），仅页面展示用',
    `host`             VARCHAR(128) NOT NULL COMMENT 'thrift 服务端地址',
    `port`             INT          NOT NULL COMMENT 'thrift 服务端端口',
    `idl_content`      TEXT                  COMMENT '内联 IDL（与 idl_location 二选一）',
    `idl_location`     VARCHAR(512) NOT NULL DEFAULT '' COMMENT 'IDL 位置：classpath:/xx.thrift 或 file:/xx.thrift',
    `framed`           TINYINT      NOT NULL DEFAULT 1 COMMENT '是否 framed 传输：1 是 0 否',
    `multiplexed`      TINYINT      NOT NULL DEFAULT 0 COMMENT '是否 multiplexed：1 是 0 否',
    `multiplexed_name` VARCHAR(128) NOT NULL DEFAULT '' COMMENT 'multiplexed 服务名',
    `status`           TINYINT      NOT NULL DEFAULT 1 COMMENT '1 启用 0 停用',
    `del_flag`         TINYINT      NOT NULL DEFAULT 0 COMMENT '0 未删除 1 已删除',
    `remark`           VARCHAR(512) NOT NULL DEFAULT '' COMMENT '备注',
    `created_at`       DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_at`       DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_gw_thrift_service_code` (`service_code`)
) COMMENT='Thrift 服务（协议转换目标）';

CREATE TABLE IF NOT EXISTS `gw_thrift_conversion` (
    `id`              BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键',
    `conversion_code` VARCHAR(64)  NOT NULL COMMENT '规则名：路由过滤器第三参 / autumn.thrift.mappings[].name',
    `conversion_name` VARCHAR(128) NOT NULL DEFAULT '' COMMENT '展示名',
    `service_code`    VARCHAR(64)  NOT NULL DEFAULT '' COMMENT '关联 gw_thrift_service.service_code',
    `method_name`     VARCHAR(128) NOT NULL DEFAULT '' COMMENT 'thrift 方法名；空=由路由/动态分发决定',
    `http_path`       VARCHAR(512) NOT NULL DEFAULT '' COMMENT '建议的 HTTP 路径（展示/联调参考）',
    `include_body`    TINYINT      NOT NULL DEFAULT 1 COMMENT '1=请求体打底 0=只看映射规则',
    `arguments_json`  TEXT                  COMMENT '入参规则 JSON：[{arg,source,key,value,required,defaultValue}]',
    `response_mode`   VARCHAR(16)  NOT NULL DEFAULT 'ENVELOPE' COMMENT '响应形态：ENVELOPE / DATA',
    `success_status`  INT          NOT NULL DEFAULT 0 COMMENT '成功时覆盖 HTTP 状态码；0=默认 200',
    `status`          TINYINT      NOT NULL DEFAULT 1 COMMENT '1 启用 0 停用',
    `del_flag`        TINYINT      NOT NULL DEFAULT 0 COMMENT '0 未删除 1 已删除',
    `remark`          VARCHAR(512) NOT NULL DEFAULT '' COMMENT '备注',
    `created_at`      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_at`      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_gw_thrift_conversion_code` (`conversion_code`)
) COMMENT='Thrift 协议转换规则（HTTP 入参/出参映射）';
```

## 4. 上线顺序（建议）

1. 执行 §2 DDL（新表，纯增量，不动既有 10 张 gw_* 表）；
2. 执行 §3 菜单语句；
3. 网关侧打开开关并下发配置（任选其一）：
   - 手工：`autumn.thrift.enabled=true` + `autumn.thrift.services[]` + `autumn.thrift.mappings[]`；
   - dashboard：「协议转换」页配置服务与规则 → 「配置同步」页预览/推送 Consul / Nacos（导出块已并入 `autumn.thrift.*`）；
4. 路由上挂过滤器：`ThriftGeneric=<service>,<method>,<conversion_code>`（service/method 可省略走动态分发）；
5. 验证：`curl --noproxy '*' -X POST http://<gateway>/thrift/DemoService/echo -H 'Content-Type: application/json' -d '{"name":"x"}'`。

## 5. 回滚

1. 路由上去掉 `ThriftGeneric` 过滤器（HTTP 路由不受影响）；
2. `autumn.thrift.enabled=false`（默认值，等于关掉）；
3. 表与菜单保留即可（无代码引用时零影响）；如需彻底清理：
   `DELETE FROM basic_menu WHERE menu_identification='gateway:thrift';`
   `DROP TABLE gw_thrift_conversion; DROP TABLE gw_thrift_service;`
