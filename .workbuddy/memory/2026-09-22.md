# 2026-09-22 日常开发：项目结构分析与问题修复

## 发现并修复的问题
1. `mvnw` 无执行权限 → `chmod +x`；`.mvn/wrapper/maven-wrapper.properties` 整个缺失 → 补建（distributionUrl 3.9.12）。
2. 16 个模块的 `AutumnGatewayApplicationTests` 仍是脚手架旧包 `xyz.wewin.autumn.autumn_gateway`，与主类包不一致 → `@SpringBootTest` 找不到 `@SpringBootConfiguration`。已全部 git mv 到各自主类同包。
3. dashboard 测试依赖局域网 MySQL（192.168.1.16）→ 加 `@Disabled`（含原因说明）。
4. `consul-config` 示例 `spring.config.import=consul:` 强依赖 Consul → 改为 `optional:consul:`。
5. **真实代码 bug**：`AutumnLoadBalancerConfiguration`（examples-discovery 和 httpexchange-provider2 两份）带 `@Configuration` 且被组件扫描进根上下文，导致 `DiscoveryClientServiceInstanceListSupplier` 在根上下文构造时 `serviceId` 为空抛异常。修复：去掉 `@Configuration`（只经 `@LoadBalancerClients(defaultConfiguration=...)` 进 lb:// 子上下文）；examples-discovery 启动类还删了过宽的 `@ComponentScan("xyz.wewin.autumn.gateway")`。
6. `autumn-gateway-discovery` 的 gateway starter 依赖未标 optional，传递进 Servlet 应用（provider2）触发 `MvcFoundOnClasspathException` → 标 `<optional>true</optional>`（与 common 模块一致）。
7. `httpexchange-api`（接口库）把 `spring-cloud-starter-consul-discovery` 强传给 provider2，与其 autumn 注册共存导致 `AutoServiceRegistration` 两个 bean 冲突 → api 模块标 optional；provider/consumer pom 里重复声明的 consul/loadbalancer 依赖已去重。
8. 根 pom：Boot parent 4.1.0 → 4.1.1（与 oauth2-authorization-server starter 版本对齐）。注意：Boot 父 POM **不托管** `spring-boot-starter-oauth2-authorization-server` 版本，必须显式指定（曾误删导致构建失败，已恢复）。
