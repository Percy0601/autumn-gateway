### 关键设计结论（后续改动请勿破坏）

- **`basic.rbac.enabled` 默认 false**，灰度开关，改配置即可回滚，不用回滚代码。
- **URL 鉴权默认拒绝**：漏配 `basic_resource` 表现为 403 报错，而非静默放行。
- **超管（`admin=1` 或 `role.master=1`）不写权限记录**，代码层短路，避免新加菜单把自己锁在门外。
- `V1` 只补唯一键与索引、不建表，因此可安全叠加到存量库；MySQL 用存储过程探测 `information_schema` 实现幂等。
- 按钮授权走 `@GrantChanged` 注解 + `AnnotationMatchingPointcut`，零 AspectJ 依赖，不误伤实体 setter。

### 踩坑（已写入文档第 8 节）

- 核心根因：`SecurityContextHolderFilter` deferred 模式（`requireExplicitSave=true`）**不会自动调用 `saveContext()`**。
  修复 = JWT 过滤器写 holder 后**显式** `request.setAttribute(ATTR_NAME, context)`。
- deferred 对象 `get()` 里绝不能再读 holder（get → supplier → get 无限递归 → StackOverflowError）。
- `.securityContext(...)` 必须写在 `authorizeHttpRequests(...)` 之前（`setSharedObject` 在 init 阶段被读取）。
- `AuthorizationManager#check` 在 7.0 改名 `authorize`，返回 `AuthorizationResult`。

## 登录安全加固 + 注释乱码纠正（21:00–21:15）
- **注释乱码根因**：迁移脚本经 `docker exec -i mysql mysql ... < file` 管道执行时，容器内 mysql 客户端字符集不是 utf8mb4（LANG 未设），UTF-8 字节被按 latin1 解释 → 服务端存成双重编码乱码。仅影响 COMMENT（数据/表注释经 JDBC 写入的都正常）。
  修复：`docker exec -i mysql mysql -uroot -p123456 --default-character-set=utf8mb4 autumn-security < fix.sql` 重放 11 个受影响列的 COMMENT（basic_user.password/login_error_count、user.uuid/password_updated_at、user_auth_account.identifier/credential_updated_at、basic_resource.http_method、basic_role_permission.create_time/update_time、basic_menu.menu_url/menu_icon）。**以后执行迁移必须带 `--default-character-set=utf8mb4`**。
- **登录失败锁定**：`UserService.authenticate` 密码错误累加 login_error_count，达到 `autumn.user.max-login-error-count`（默认 5）置 status=0 自动禁用 + WARN 日志；`BasicUserService.updateStatus` 启用账号时清零计数。锁定后需管理员在用户管理页重新启用。
- **登录验证码**：新增 `security/CaptchaService`（SVG 零依赖，答案存内存 ConcurrentHashMap 按 captchaId 关联——适配 STATELESS 无 session 架构；授权服务器那版是存 session 的，别照搬）+ `controller/CaptchaController`（GET /api/captcha 返回 {captchaId, img:dataURI}）。`LoginRequest` 加 captchaId/captcha；`LoginController.account` 在认证前校验，失败响应带 message（验证码错误/账号或密码错误/账号已禁用）；SecurityConfig 放行 /api/captcha。配置 `autumn.captcha.enabled/length/ttl-seconds`。
- **前端**：`views/login/index.vue` 加验证码输入框 + 图片（点击刷新），onMounted 拉取，失败自动刷新并展示服务端 message。

## 授权（Authorization）落地 + 重置密码（21:01–21:30）
