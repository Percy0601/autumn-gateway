# 网关可视化配置 — 常用配置参数清单（SCG 5.0.3）

> 目标：为 dashboard /dashboard-ui 的「可视化配置 spring-cloud-gateway」提供完整参数输入。
> 配套文档：《网关可视化配置 - 表结构设计.md》（5 张
> `gw_*`
> 表 DDL 已落地）；本文按「配置项 → 表 → 导出」梳理每个参数。
> **本文所有参数均已对照 5.0.3 源码核对**
> （Config 类字段），不是凭记忆整理。

## 0. 口径与来源



| 项     | 值                                                                                                                         |
| ----- | ------------------------------------------------------------------------------------------------------------------------- |
| 网关依赖  | `spring-cloud-gateway-server-webflux` **5.0.3**（Spring Boot 4.1.1）                                                        |
| 配置前缀  | `spring.cloud.gateway.server.webflux.*`（SCG 5 新前缀，旧 `spring.cloud.gateway.*` 不再生效）                                        |
| 核对来源  | ① 官方 Common application properties 附录（2026-10 版）；② `spring-cloud-gateway-server-webflux-5.0.3-sources.jar` 各 `Config` 类字段 |
| 可配置判定 | **配置驱动** = 能由 properties/yaml 表达、可落库导出；**代码驱动** = 参数含 Java lambda/Bean 引用，只能 DSL                                          |

### 0.1 四个配置对象与表落点



```
全局标量（server.webflux.* / autumn.*）──→ gw_config_item（按 profile 隔离）
路由（routes[i]）──────────────────────→ gw_route
  └ 断言 predicates[j] ────────────────→ gw_route_predicate
  └ 过滤器 filters[j] ─────────────────→ gw_route_filter
全局默认过滤器 default-filters[i] ─────→ gw_global_filter
工厂参数 schema（哪些参数/必填/单例）──→ 代码侧静态注册表（不落库，前端启动拉一次）
```

### 0.2 参数值形态（决定前端控件）



| 形态              | 含义        | 前端控件       | 例                                   |
| --------------- | --------- | ---------- | ----------------------------------- |
| scalar-required | 必填        | 输入框 + 必填校验 | `uri`、Authz `mode`                  |
| scalar-optional | 可留空走默认    | 输入框        | `server.port`                       |
| list            | 可多项       | 动态行表格      | Path `patterns`、Method `methods`    |
| enum            | 枚举        | 下拉         | Dedupe `strategy`                   |
| bool            | 开关        | switch     | `enabled`、Path `matchTrailingSlash` |
| sensitive       | 加密落库 + 掩码 | 密码框        | `jwt.secret`、`client-secret`        |
| singleton       | 一条路由只准挂一次 | 下拉置灰       | Authz、StripPrefix                   |
| repeatable      | 可挂 N 次    | 动态行        | AddRequestHeader                    |

## 2. 路由级配置（→ `gw_route`）

对应 `…server.webflux.routes[i]`，一条路由 = 一个下游服务：



| 字段              | 必填       | 唯一        | 形态       | 导出 key                                         |
| --------------- | -------- | --------- | -------- | ---------------------------------------------- |
| route\_code（id） | 是        | 全局唯一      | 标量       | `routes[i].id`                                 |
| route\_name     | 否        | —         | 标量       | 备注，不导出                                         |
| uri             | 是        | 每路由一个     | 标量       | `routes[i].uri`（`lb://x` 或 `http://host:port`） |
| order           | 否 (默认 0) | —         | int      | `routes[i].order`                              |
| enabled         | 是        | —         | switch   | `routes[i].enabled`（SCG 5 原生字段）                |
| predicates      | ≥1       | list      | 动态行（AND） | `routes[i].predicates[j].name/.args.*`         |
| filters         | 否        | list（带顺序） | 动态行      | `routes[i].filters[j].name/.args.*`            |
| metadata        | 否        | map       | KV       | `routes[i].metadata.*`（如 `metadata.cors`）      |

## 3. 断言工厂（RoutePredicateFactory）清单

> 落点：
> `gw_route_predicate`
> （args 存 args_json）；
> **工厂参数 schema 放代码侧注册表**
> 。
> 配置形式一律用长写
> `name= + args.xxx=`
> ，不要短写（短写依赖 shortcutFieldOrder，逗号 / 冒号值会错位）。



| 工厂名                      | 参数（args key）              | 类型 / 默认              | 每路由唯一性 | 可配置性    | 说明 / 坑                                                            |
| ------------------------ | ------------------------- | -------------------- | ------ | ------- | ----------------------------------------------------------------- |
| **Path**                 | `patterns`                | list，`patterns.0` 索引 | 通常一条   | ✔       | 逗号分隔多模式；`matchTrailingSlash` 默认 true；提取 `{segment}` 模板变量          |
| **Method**               | `methods`                 | list                 | —      | ✔       | `GET,POST`；大小写敏感                                                  |
| **Host**                 | `patterns`                | list                 | —      | ✔       | Ant 风格 `**.somehost.org`，`.` 为分隔符；支持 `{sub}.host` 模板变量            |
| **Header**               | `header` + `regexp`       | string               | —      | ✔       | 头名 + Java 正则                                                      |
| **Query**                | `param`(必) + `regexp`(可)  | string               | —      | ✔       | `Query=green` 只查存在；`Query=red, gree.` 查值匹配                        |
| **Cookie**               | `name` + `regexp`         | string               | —      | ✔       | Cookie 名 + 正则                                                     |
| **RemoteAddr**           | `sources`                 | list（≥1，CIDR）        | —      | ✔       | `192.168.1.1/24`；默认取 socket 远端 IP                                 |
| **XForwardedRemoteAddr** | `sources`                 | list（≥1，CIDR）        | —      | ✔       | SCG 5 新增；按 `X-Forwarded-For` 匹配；信任跳数 `maxTrustedIndex` 是代码级       |
| **Weight**               | `group` + `weight`        | string+int           | —      | ✔       | 同 group 内按权重分流（如 8:2），**需同一 group 至少两条路由配对**                      |
| **Version**              | `version`                 | string               | —      | ✔       | SCG 5 新增；`1.3` 精确匹配 / `1.1+` 基线；需先配 `spring.webflux.apiversion.*` |
| **After**                | `datetime`                | ZonedDateTime        | —      | ✔       | `2017-01-20T17:42:47.789-07:00[America/Denver]`                   |
| **Before**               | `datetime`                | ZonedDateTime        | —      | ✔       | 同上                                                                |
| **Between**              | `datetime1` + `datetime2` | ZonedDateTime        | —      | ✔       | 时间窗（维护窗口场景）                                                       |
| **ReadBody**             | `inClass` + `predicate`   | Class + lambda       | —      | ✖ 仅 DSL | 断言参数是 Java Predicate，yaml 无法表达                                    |
| CloudFoundryRouteService | —                         | —                    | —      | ✖       | 平台专用，忽略                                                           |

> 前端 schema 建议：Path/Host/RemoteAddr/XForwardedRemoteAddr 的
> `patterns`
> /
> `sources`
> 用「动态行 + 单行模式输入」；
> datetime 用日期时间选择器生成 ISO8601 + 时区串；Version 用文本 + 帮助文案（
> `1.1+`
> 语法）。

## 4. 过滤器工厂（GatewayFilterFactory）清单

> 落点：路由级 →
> `gw_route_filter`
> ；
> `default-filters`
> →
> `gw_global_filter`
> （同 schema）。
> 下表每行标注：
> **singleton**
> （一条路由只准挂一次）/
> **repeatable**
> （可挂多次）/ 依赖。

### 4.1 常用（v1 建议直接暴露）



| 工厂名                               | 参数（args key）                                                                                                                                                  | 唯一性        | 可配置性 | 说明 / 坑                                                                         |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- | ---- | ------------------------------------------------------------------------------ |
| **AddRequestHeader**              | `name` + `value`                                                                                                                                              | repeatable | ✔    | 加请求头；value 支持 `{segment}` 模板变量                                                 |
| **AddResponseHeader**             | `name` + `value`                                                                                                                                              | repeatable | ✔    | 加响应头                                                                           |
| **SetRequestHeader**              | `name` + `value`                                                                                                                                              | repeatable | ✔    | 覆盖请求头                                                                          |
| **SetResponseHeader**             | `name` + `value`                                                                                                                                              | repeatable | ✔    | 覆盖响应头                                                                          |
| **AddRequestParameter**           | `name` + `value`                                                                                                                                              | repeatable | ✔    | 加查询参数                                                                          |
| **RemoveRequestHeader**           | `name`                                                                                                                                                        | repeatable | ✔    | 删请求头                                                                           |
| **RemoveResponseHeader**          | `name`                                                                                                                                                        | repeatable | ✔    | 删响应头                                                                           |
| **RemoveRequestParameter**        | `name`                                                                                                                                                        | repeatable | ✔    | 删查询参数                                                                          |
| **StripPrefix**                   | `parts`(int 默认 1)                                                                                                                                             | singleton  | ✔    | 剥掉前 N 段路径；`/api/order` + StripPrefix=1 → `/order`                              |
| **PrefixPath**                    | `prefix`                                                                                                                                                      | singleton  | ✔    | 加路径前缀；`/api`                                                                   |
| **RewritePath**                   | `regexp` + `replacement`                                                                                                                                      | singleton  | ✔    | 路径正则重写；`/api/(?<seg>.*) → /$\{seg}`                                            |
| **SetPath**                       | `template`                                                                                                                                                    | singleton  | ✔    | 直接用模板覆盖路径；`/order/{segment}`                                                   |
| **SetStatus**                     | `status`                                                                                                                                                      | singleton  | ✔    | 强制响应状态码；`GONE`、`BAD_REQUEST`；配合 `…set-status.original-status-header-name` 保留原码 |
| **RedirectTo**                    | `status`(3xx) + `url` + `includeRequestParams`(新，默认 false)                                                                                                    | singleton  | ✔    | 302/301 重定向；includeRequestParams 把原查询参数带过去                                     |
| **RequestSize**                   | `maxSize`(DataSize 默认 5MB)                                                                                                                                    | singleton  | ✔    | 请求体上限，超限返回 413                                                                 |
| **RequestHeaderSize**             | `maxSize`(默认 16000B) + `errorHeaderName`                                                                                                                      | singleton  | ✔    | 请求头体积上限                                                                        |
| **MapRequestHeader**              | `fromHeader` + `toHeader`                                                                                                                                     | repeatable | ✔    | 头改名（拷贝值）                                                                       |
| **DedupeResponseHeader**          | `name`(可多个) + `strategy`(RETAIN\_FIRST 默认 / RETAIN\_LAST/RETAIN\_UNIQUE)                                                                                      | repeatable | ✔    | 响应头去重                                                                          |
| **AddRequestHeadersIfNotPresent** | `headers`（KeyValueConfig 列表）                                                                                                                                  | repeatable | ✔    | 不存在才加；properties 表达较绕，建议 yaml                                                  |
| **SetRequestHostHeader**          | `host`                                                                                                                                                        | singleton  | ✔    | 覆盖下游 Host 头                                                                    |
| **SetRequestUri**                 | `template`                                                                                                                                                    | singleton  | ✔    | SCG 5 新增；直接改下游 uri                                                             |

### 4.2 项目自有工厂（autumn-gateway-starters）



| 工厂名                   | 参数                                                                                                                    | 唯一性           | 说明                                                                                   |

| **Authz**             | `mode`(authenticate/authorize) + `appCode` + `permitAll` + `failOpen`                                                 | **singleton** | 认证 / 鉴权；`shortcutFieldOrder=[mode, appCode]`                                         |
| **MemoryRateLimiter** | `keyType`(IP/HEADER/PATH) + `headerName` + `replenishRate` + `burstCapacity` + `timeWindowSeconds` + `antPathConfigs` | **singleton** | Bucket4j 内存限流；`shortcutFieldOrder=[replenishRate, burstCapacity, timeWindowSeconds]` |

### 4.4 全局过滤器（GlobalFilter，代码 Bean）

SCG 内置一组 GlobalFilter（`…global-filter.*.enabled` 可关）：`netty-routing`、`load-balancer-client`、`route-to-request-url`、`forward-routing`、`websocket-routing`、`adapt-cached-body`、`local-response-cache` 等。

**本项目 starters 未注册自定义 GlobalFilter**（Authz 是 FilterFactory，不是 GlobalFilter）→ 不产生表数据，仅可能出现在导出配置的 `global-filter.*.enabled=false` 关闭项里。

## 5. 与可视化后台的衔接要点

### 5.1 注册表（代码侧静态注册表，不落库）

按表结构设计 §6.1 结论：过滤器 / 断言工厂的元数据 + 参数 schema 放 **Java 常量注册表**，

`/api/gw/filter-definitions` 一次性返回给前端。每条 schema：



```
{
  "name": "Authz",
  "type": "filter",            // filter | predicate
  "displayName": "认证/鉴权",
  "singleton": true,
  "args": [
    { "key": "mode", "label": "模式", "type": "enum", "required": true,
      "options": ["authenticate", "authorize"] },
    { "key": "appCode", "label": "应用编码", "type": "string", "required": true },
    { "key": "permitAll", "label": "匿名放行路径", "type": "list", "required": false },
    { "key": "failOpen", "label": "鉴权失败放行", "type": "bool", "required": false, "default": "false" }
  ]
}
```

### 5.2 v1 暴露范围建议（按价值排序）



1. **路由 CRUD**（gw\_route）：uri/order/enabled/predicates/filters —— 核心页面

2. **Authz / MemoryRateLimiter** 两个项目工厂（singleton 置灰逻辑）

3. **路径类**：StripPrefix / PrefixPath / RewritePath / SetPath（+ Path/Method/Host 断言）

4. **头操作类**：Add/Set/Remove Request/Response Header、AddRequestParameter、MapRequestHeader、DedupeResponseHeader

5. **全局标量**：server.port、httpclient 超时 / 连接池、trusted-proxies、autumn.authz.\*（含敏感字段掩码）

6. **default-filters**（gw\_global\_filter）：Authz/MemoryRateLimiter/StripPrefix 等挂在全局

v1 建议**只读不暴露**：Retry（参数多）、CircuitBreaker（需依赖）、RequestRateLimiter（无 Redis）、ModifyBody（lambda）、ReadBody（lambda）。

### 5.3 导出易错点（沿用表结构设计 §4）



* 一律长写 `name=` + `args.xxx=`；`shortcutFieldOrder` 只影响短写，别依赖。

* list 参数 properties 用逗号分隔；**yaml 值一律加引号**（`真`、`1分钟`、`=` 会被解析错）。

* 索引从 0 连续重编；SQL textarea 推荐导出 yaml（properties 续行转义易碎）。

* `enabled=false` 的已配置路由 / 过滤器也要导出（SCG 5 原生支持关单条），不能靠跳过实现停用。
